## Project Name
F&M E_Trading Platform - Online Shopping System

## How It Works
This is a simple online shopping platform where:
- Admins can add and manage products
- Users can browse and buy products
- Users can view their purchases and generate invoices
- Supports Mobile Money and PayPal payments

## Database Tables
1. Users - Stores user information
2. Products - Stores product information
3. Stocks - Tracks user purchases
